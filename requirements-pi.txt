# Pi-only runtime deps (real GPIO/SPI + panel driver). Installed by
# scripts/deploy.sh and by docs/runbook.md §5.
#
# On Raspberry Pi OS the C-extension packages below are expected to come from
# apt into a `--system-site-packages` venv:
#   python3-lgpio python3-spidev python3-numpy python3-pil python3-gpiozero
# piwheels publishes no lgpio/spidev wheels for cp313 (Trixie-era images), and
# building them from sdist needs swig + Python headers (issue #66).
# scripts/deploy.sh installs those apt packages before pip runs, so pip finds
# lgpio/spidev/numpy/Pillow already satisfied and does not try to compile them.
#
# They stay listed here so a plain `pip install -r requirements-pi.txt` still
# resolves a complete environment on platforms where wheels *are* available.
-r requirements-base.txt
